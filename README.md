# StickShield
StickShield is a flexible acoustic metamaterial sticker attached to the microphone surface. It defends against various voice attacks such as adversarial, inaudible, and laser attacks by absorbing sound in specific frequency bands, while maintaining normal speech intelligibility.  
The system can be fabricated simply by using a 3D printer following the provided drawings. The drawings present a single basic unit of the flexible metamaterial. Users can fine-tune this unit according to the dimensions of the target smart device's microphone, and then combine multiple units through copy and paste for joint printing to adapt to different microphones. Each unit consists of a top membrane structure and a rear box-like structure, which require different materials: the former uses silicone rubber (E = 9 × 10⁶ Pa, ρ = 1200 kg/m³), and the latter uses soft polyurethane rubber (E = 6.5 × 10⁶ Pa, ρ = 1040 kg/m³). After printing, simply attach the structure onto the device's microphone with the top side facing up to effectively defend against various voice assistant attacks.  
---- Files with the .SLDPRT extension need to be opened with SolidWorks, allowing adjustments to the structure; .STL files can be used to directly print a single unit.
